# Client Compass v1.9.8

## Simplified report workspace
- Rebuilt finished client reports around a single-pane workspace rather than the original multi-step generator flow.
- Moved the client identity below the application header so the practice name is visually distinct from the Advantage Technologies brand bar.
- Removed the sticky generator command center, progress rail, finished-package explainer, and permanent HIPAA results section from completed client reports.
- Kept the report itself centered on two primary cards: the technology/security summary and the agreed plan.

## Focused controls
- Sources are now opened from the compact status strip in a focused modal where lifecycle/ScalePad, security, and supporting files can be added, replaced, or refreshed.
- Replacing or refreshing sources rebuilds an already-finished client report so the current package stays current.
- HIPAA readiness is summarized in the status strip with the current score and a chevron; opening it launches the editable HIPAA review directly.
- Presentation, PDF download, next-step selection, report tailoring, and secondary preparation actions remain available without a scrolling control panel.

## Hardware visibility
- Added a compact hardware inventory directly below the two main report cards so the workspace shows the devices included in the presentation.
- The inventory includes brief device, type, model, operating-system, age, and lifecycle status fields plus physical/virtual and priority totals.
- The compact inventory is height-limited with its own vertical scroll so large client inventories do not turn the report workspace back into a long generator page.

## Presentation fit
- Reworked the presentation hardware table to use fixed-layout percentage columns, wrapping, and viewport-constrained containers.
- All ten hardware columns now fit inside presentation mode without a horizontal scrollbar.

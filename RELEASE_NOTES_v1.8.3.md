# Client Compass v1.8.3

## Card detail segment interaction fix

- Fixed card-back detail tiles so the visible back face is the only card face that can receive pointer input after a flip.
- Clicking a detail tile now reliably selects that exact segment and filters the client list below.
- Clicking the selected tile again clears the segment.
- Selected tiles now use a stronger visual state and display **✓ Filtering below** directly inside the tile.
- Applies across every Project Coverage and Health Priority card detail section.
- Preserves the active-segment banner and **Clear segment** action above the client list.

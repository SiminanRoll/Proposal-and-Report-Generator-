# Version 1.0.1.6

- Adds a **Download PDF** action to the finished package and live presentation header.
- Opens a local, print-ready landscape copy and launches the browser's Save as PDF workflow.
- Uses page breaks between major presentation sections while allowing long inventory and readiness content to continue cleanly.
- Uses the client name and report type for the print-document title and suggested PDF filename.
- Changes the browser tab title during presentation mode to a client-facing title such as `Client Name — Technology Health Review`.
- Restores the internal application title when presentation mode closes.
- Keeps PDF generation browser-only so client source data is not uploaded to a server.

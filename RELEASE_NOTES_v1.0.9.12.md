# Client Compass v1.0.9.12

## Recent reports health sorting
- The Health column can now be clicked to sort by Replacement Now count.
- First click sorts highest red count first, second click sorts lowest red count first, and a third click returns to normal recent order.
- Search wording is simplified to “Search recent.”

## Data import polish
- The Ninja spreadsheet/source title in the import drop area is now muted and lightly embossed into the background rather than appearing as heavy dark headline text.

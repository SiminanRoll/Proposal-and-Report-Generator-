# Client Compass v1.0.9.29

- Adds reusable Map lenses powered only by saved Segment Manager definitions; there is no second map-specific segment system.
- Allows multiple segment cards to combine with ALL or ANY logic, so combinations such as Server 2012 + Windows 10, quote status, review status, and other saved segments can be visualized geographically.
- Makes state selection an additive WHERE scope on the map, including reliable selection while zoomed and panning.
- Keeps Clients, Need, and Value as the three map concentration views after segment and geography filtering.
- Matches map segment cards to the compact saved-segment card language used in the navigation menu.
- Standardizes top-level Client Compass page titles on the quiet embossed/stamped gray Report Generator treatment.

# Client Compass v1.0.9.13

## Segment Manager
- Added a new Segment Manager to the primary Client Compass navigation.
- Managed segments appear below the system navigation as custom-color hot buttons with configurable names and icons.
- Segment rules can target client size, red/yellow/green lifecycle counts, servers, workstations, estimated need, priority score, review age, quote age, quote status, Captain's Log activity, assigned owner, location/state text, or client name.
- Segments support match-all / match-any logic plus manual include and exclude overrides.
- Segment cards flip between enrolled-client counts and total estimated need plus up to three user-selected tracking stats; estimated need stays fixed as the lead dollar metric.
- Segment detail pages show the enrolled client book with lifecycle health, managed asset count, estimated need, last review, Captain's Log tracking, client detail access, and report access.
- Segment order controls the order of segment hot buttons in the left menu.

## Report Generator polish
- Preserved the sortable red/yellow/green Health column and “Search recent” behavior from v1.0.9.12.
- Restyled the Report Generator page title as a dimmed, pressed/debossed background label instead of a bold dark headline.

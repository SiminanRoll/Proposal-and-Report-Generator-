# Version 1.0.3.13

## Server-planning language

- Reframed aging server recommendations as a planning decision rather than an automatic hardware purchase.
- The default server headline is now **Plan the server's next step**.
- When both the primary server and Cloud Plus backup server are involved, the headline is **Plan the next step for both servers**.
- Client-facing copy now explains that the appropriate path may be replacement, migration, or safe retirement based on the practice's future software plans.
- The recommended consultation is now a **server planning review** focused on dependencies and transition choices.

## Shorter action cards

- Added dedicated concise action titles and details instead of repeating the full planning paragraph.
- Server action cards now use:
  - Determine the direction
  - Confirm the full scope
  - Build the transition plan
- HIPAA, security, workstation, and estimate actions were shortened for faster scanning.
- Long timing and ownership labels were shortened where possible.

## Lifecycle badges

- High-level server and Cloud Plus backup server priority cards now show **Plan next step**.
- Workstations and other directly replaceable equipment continue to show **Replace now**.
- The detailed inventory retains the technical lifecycle status so the underlying condition is not hidden.

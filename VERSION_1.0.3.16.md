# Version 1.0.3.16

## HIPAA pre-meeting packet

- Includes only unanswered or deferred client-facing HIPAA questions.
- Omits any question that already has an answer in the workspace.
- Never asks the client to answer Advantage-owned endpoint-protection or backup-coverage checkpoints.
- Summarizes those two Advantage-confirmed items on the overview page instead.
- Reduces a fully open pre-meeting questionnaire from 12 questions to 10 client-facing questions.
- Dynamically reduces the page and field count as answers are completed.
- Uses client-facing explanatory copy throughout; internal wording such as "Advantage proposes" was removed.

## Advantage-confirmed HIPAA answers

- Endpoint protection and security monitoring is automatically answered Yes and marked technically verified.
- Backup protection and recovery coverage is automatically answered Yes and marked technically verified.
- Cached projects refresh these two managed-service answers during project normalization.

## Finished client PDF

- Advantage-owned technical checkpoints are also excluded from the unanswered-question appendix.
- Return instructions continue to appear only when client-facing questions remain unanswered.

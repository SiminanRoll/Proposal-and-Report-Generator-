# Phase 3 Acceptance — Outcome Builder

## Goal

Turn approved source intelligence into a polished, client-facing report or proposal without asking the employee to assemble document sections.

## Completion checkpoints

- One-click outcome generation after required confirmations are complete.
- Executive summary composed from source evidence and client context.
- Client-friendly findings ranked by priority, attention, and healthy status.
- Recommended plan generated from the categories found in the source material.
- Full-screen local presentation mode with overview, findings, and plan.
- Self-contained interactive HTML download for local sharing or printing.
- Title and executive summary can be corrected without exposing a complicated editor.
- Source intelligence remains available in a collapsed technical drawer.
- Replacing a source clears the generated outcome so it can be refreshed from current evidence.
- No source files or client data are transmitted to a server.

# Phase 2 Acceptance — Source Intelligence

Phase 2 is accepted when:

- A user can create all three project types from the web interface.
- Required files are analyzed before the project opens.
- The supplied RFT structure yields device, server, OS, network, application, security, backup, patching, and lifecycle facts.
- ScalePad, Huntress, legacy proposal, PDF, DOCX, TXT, and image sources enter a common analysis record.
- Every extracted fact retains a source file and evidence description.
- Low-confidence sources become a review item instead of silently becoming truth.
- The A360 proposal path asks only the small set of human questions that source material cannot answer.
- Source files can be added or replaced inside an existing project and intelligence rebuilds automatically.
- No Python, BAT, PowerShell, or custom localhost launcher is present.
- Phase 1 browser projects migrate without being discarded.

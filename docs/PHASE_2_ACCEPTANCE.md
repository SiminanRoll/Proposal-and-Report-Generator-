# Phase 2 Static Acceptance — Source Intelligence

Phase 2 is accepted when:

- All three project types can be created from a statically exported site.
- Required files are analyzed locally before the project opens.
- The supplied RFT yields device, server, OS, network, application, security, backup, patching, and lifecycle facts.
- ScalePad, Huntress, legacy proposal, PDF, DOCX, TXT, and image sources enter a common analysis record.
- Every extracted fact retains a source file and evidence description.
- Low-confidence sources become a review item instead of silently becoming truth.
- The A360 proposal path asks only the small set of human questions the source material cannot answer.
- Source files can be added or replaced inside an existing local project.
- Project backups can be downloaded and restored explicitly.
- No API route, Dockerfile, Python, BAT, PowerShell, custom launcher, database, or hosted file storage is present.
- `next build` emits the deployable site to `out/`.

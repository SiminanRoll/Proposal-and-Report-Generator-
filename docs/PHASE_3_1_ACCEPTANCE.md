# Phase 3.1 Acceptance — Combined Current Client Report

## Goal

Combine the actual ScalePad hardware-lifecycle report and Huntress threat report into one polished client review, using the source values rather than generic PDF themes.

## Completion checkpoints

- ScalePad summary totals populate workstation, server, VM, network, replacement, and OS-support metrics.
- ScalePad detail pages populate a named device inventory with model, age, warranty, OS, RAM, CPU, and storage.
- Multi-line device names remain intact.
- Huntress summary values populate protected entities, events, signals, investigations, and incidents.
- Huntress ransomware-canary, managed-antivirus, persistent-foothold, and process-insight values are retained.
- Zero incidents are presented as a positive monitored result, not as missing protection.
- The client presentation combines technology health, security protection, planning, and device evidence.
- The portable HTML report contains the same source-derived values and can be printed or saved as PDF.
- Raw source documents remain local to the browser and are never uploaded.

# Shared Project Model

Every workflow produces the same core project structure:

- project identity and type
- client and contacts
- locations
- source documents
- environment facts
- pain points
- findings and evidence
- recommendations
- services, products, SKUs, and quantities
- pricing
- photos
- presentation settings
- terms and signature state
- internal communication handoff

The schema is versioned so future importers and migrations can evolve safely.

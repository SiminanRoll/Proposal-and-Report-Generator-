# Version 1.0.3.7

## Print-friendly client PDF

- Client reports now export as upright US Letter portrait documents instead of rotated widescreen pages.
- Uses a light, ink-conscious theme while preserving Advantage typography, status colors, and report hierarchy.
- Consolidates security and lifecycle status onto one page and keeps the recommended plan, inventory, recap, and HIPAA follow-up concise.
- Hardware inventory is limited to ten compact rows per page and keeps the full reportable dataset intact.
- Outstanding HIPAA questions remain fillable and are shown two per page. Completion fields and return instructions appear only on the final follow-up page and only when questions remain.
- Proposal PDFs remain widescreen so the approved proposal presentation layout is unchanged.

## Presentation polish

- Removed the visible “click to choose a date” scheduling hint from Planning and Recap.
- Reduced the height and padding of Planning and Recap summary cards.
- Increased and standardized summary-number sizing so Healthy Assets, Health Priorities, Security Follow-Ups, and Recap metrics use the same visual scale.

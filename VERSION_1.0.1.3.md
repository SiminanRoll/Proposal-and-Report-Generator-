# Version 1.0.1.3

- Network & Lifecycle scoring now weights servers and other business-critical systems more heavily than ordinary workstations.
- A server marked for replacement prevents the lifecycle score from presenting as Strong until the issue is addressed.
- Replaced the vague “Resilience & Planning” card with “Action Readiness.”
- Action Readiness measures whether findings have clear next steps, ownership, estimates, and follow-through.
- Corrected the Planning presentation layout so it is centered across the widescreen stage.

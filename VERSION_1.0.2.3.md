# Version 1.0.2.3

This release expands the client-facing technology health report in three areas:

- Adds a polished security close describing managed 24/7 monitoring, advanced threat detection, anti-malware, anti-ransomware safeguards, advanced threat response, event follow-up, and the need to onboard new or replacement computers before they join the network. The language describes the service without guaranteeing that every threat can be prevented.
- Detects Cloud Plus BDR backup emergency servers by CPBR device naming or EQUUS hardware identification. These systems now appear in inventory, lifecycle counts, replacement priorities, planning, HTML, and PDF output as their own backup-server category.
- Uses adaptive hardware next steps: one to four workstation-only replacements normally lead to a phone or remote estimate review; more than four computers or any server/backup-server replacement leads to onsite project planning. Server-related projects are scoped as a whole rather than recommending the server now and related aged systems later.

Lifecycle totals continue to use one physical-device dataset so primary servers, Cloud Plus BDR backup servers, and workstations reconcile across the report.

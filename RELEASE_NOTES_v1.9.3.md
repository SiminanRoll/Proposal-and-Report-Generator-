# Client Compass v1.9.3

## Inventory integrity diagnostics

- Moves inventory reconciliation warnings out of the client-facing presentation and PDF surfaces.
- Pauses the finished presentation and PDF when source inventory counts do not reconcile.
- Adds a prominent internal Inventory integrity check with one-click **Download diagnostics**, **Edit hardware inventory**, and **Refresh source data** actions.
- Makes reconciliation language explain the actual source discrepancy: source summary totals versus identifiable detailed inventory records.
- Expands the diagnostic CSV with source-reported total, report total, source-summary variance, and category-level count variance so a missing workstation/server/VM can be isolated quickly.
- Keeps the existing Data → Inventory diagnostics control as a secondary access point.
